# Aeroderivative teaching schematic

Open `index.html` in a browser. The page is one file and does not need a server or an internet connection.

It is an independent teaching schematic of the LM2500, LM6000, and LMS100 arrangements: cutaway, explode, airflow, and the published ratings kept on the boundary they were published with. Annulus sizes and blade counts are enlarged so the gas path can be read. The LM6000 length on screen is the published 4.91 m. The other two lengths are schematic.

LM2500, LM6000, LMS100, and SPRINT are trademarks of their owners. This page is not an OEM drawing, an inspection limit, or a heat balance.

The 3D view uses [Three.js](https://github.com/mrdoob/three.js) r170, included in the file under the MIT license. The license text is at the bottom of `index.html`.

To change the words on the page, open `index.html` in a text editor and search for `START OF TURBINE INFORMATION`.
